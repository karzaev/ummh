Local dictation for macOS with Russian support. No cloud processing or LLM rewriting.

**Apple Silicon · macOS 27+**

Open the DMG and drag ummh into Applications. This build is **ad-hoc signed and
not notarized by Apple**. macOS may require explicit first-launch approval:
[Apple's guidance](https://support.apple.com/en-gb/102445).

Hold Right Command, speak and release to copy. Enable automatic paste in Settings
if desired. Escape cancels. Live text is optional.

Models download on first use. Recognition runs on the Mac; ummh does not upload
audio or transcripts. Microphone and Accessibility access are required.

GPLv3 source and build instructions are included with this tag. Recognition uses
[FluidAudio](https://github.com/FluidInference/FluidAudio/tree/762baf6733ca0f0dbeb1ce335363fc75066bd2c9).
