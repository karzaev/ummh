- `Sources/ummh/WordAgreementEngine.swift` retains the agreement algorithm
  from `VoiceInk/Infrastructure/Providers/Transcription/FluidAudio/Streaming/WordAgreementEngine.swift`.
- `Sources/ummh/SpeechEngine.swift` adapts the VAD, preview-window, tail and
  short-session batch fallback flow from `FluidAudioStreamingProvider.swift`
  and `FluidAudioTranscriptionService.swift`.
- `Sources/ummh/Interface.swift` adapts the waveform amplitude/phase formula
  from `AudioVisualizerView.swift`, the live-text layout and rotating-arc
  `ProcessingIndicator` from `RecorderComponents.swift` (larger dimensions
  and TimelineView-driven rotation).
- `Sources/ummh/Hotkey.swift` uses the event-tap lifecycle pattern from
  `ShortcutMonitor.swift`; it is a smaller Accessibility-authorized event tap
  that returns all original events unchanged.
- The screen fallback order follows VoiceInk's `RecorderScreenResolver.swift`.

`resources/sounds/start.mp3` and `finish.mp3` are VoiceInk's default
`sound5.mp3` and `sound6.mp3`, used at volume 0.3.
